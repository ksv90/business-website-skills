  соответствие лицензий/инструкций и release-конфигурации.

  заблокированный доступ → unknown, неподтверждённый MAX не генерируется, демоформа

  нет PyYAML. Вместо установки Python-зависимостей использованы проверки Node и Psych.
- Начальный запуск из login-shell выбрал Node 20; после выбора доступного Node 24 все
  указанные проверки выполнены успешно. Требование Node 22.18+ указано в пакете.
- Не выполнялись реальная кампания, пользовательский CAPTCHA-сценарий, самостоятельный
  полевой прогон агента, создание клиентского сайта или визуальная проверка такого сайта.
- GitHub auth сообщает о недействительном токене; удалённый репозиторий и Release не созданы,
  workflow на GitHub не запускались. Локальный репозиторий без staging/коммитов/тегов.

Следующая проверка качества поведения — небольшой полевой пилот по выбранным пользователем
географии и нише. Требует отдельной постановки задачи, а не изменения этих результатов.
