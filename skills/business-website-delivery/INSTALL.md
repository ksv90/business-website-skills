# Установка и переносимость

Основной вариант — глобальная установка для текущего пользователя. Оба скилла
устанавливаются полными папками в пользовательский каталог Codex и доступны ему
в любом проекте. Установка использует штатные средства системы; Node.js, npm, Git
и права администратора не требуются.

## Быстрая установка

Нужен доступ к GitHub. Для macOS используются Bash, curl, unzip и shasum; для Windows —
Windows PowerShell 5.1+ и стандартные средства работы с ZIP/SHA-256.

**macOS, Терминал:**

```sh
bash -o pipefail -c 'curl -fsSL https://github.com/ksv90/business-website-skills/releases/latest/download/install.sh | bash'
```

**Windows, PowerShell:**

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://github.com/ksv90/business-website-skills/releases/latest/download/install.ps1')))
```

Команды скачивают и исполняют установщик из последнего Release — используйте их для
доверенного издателя. Чтобы сначала просмотреть код, скачайте `install.sh` или
`install.ps1` из Release и откройте как текст. Для Windows команда создаёт блок кода
в текущем PowerShell и не требует изменения ExecutionPolicy. Организационные правила
могут ограничивать исполнение такого кода; в этом случае используйте ручную установку.

Адрес `ksv90/business-website-skills` пока планируемый. До публикации первого Release
команды не работают. Если адрес изменится, замените его в документации и установщиках.

## Что делает установщик

1. Проверяет, что одноимённых папок ещё нет. Существующие скиллы, включая локальные
   правки, не перезаписывает. Если найден хотя бы один выбранный скилл, останавливается.
2. Скачивает ZIP и контрольные суммы той версии, с которой выпущен установщик.
   Поэтому загрузка архивов не переключится на другой релиз в середине установки.
3. Сверяет SHA-256, проверяет пути архива и наличие SKILL.md.
4. После проверки обоих архивов переносит папки в пользовательский каталог и выводит пути.
   При ошибке загрузки или контрольной суммы ничего не устанавливает.

Контрольные суммы выявляют повреждение архива и не заменяют доверие к издателю.
Установка не даёт агенту доступ к аккаунтам, браузеру, API или хостингу.

## Расположение и выбор агента

Для Codex используется пользовательский каталог из
[официальной документации OpenAI](https://learn.chatgpt.com/docs/build-skills):

| Система | Папка по умолчанию |
| --- | --- |
| macOS | `~/.agents/skills/` |
| Windows | `%USERPROFILE%\.agents\skills\` |

Установщики создают внутри `business-lead-research/` и `business-website-delivery/`.
Для другого агента укажите его документированный каталог параметром назначения.
Например, для Claude Code — пользовательский `.claude/skills/`. Установка в Windows
не распространяется на отдельную среду WSL; в ней устанавливайте скиллы отдельно.

Параметры удобнее передавать скачанному и просмотренному установщику.

**macOS**, установить только скилл поиска в папку Codex:

```sh
bash ./install.sh --skill business-lead-research
```

Другой каталог, например пользовательская папка Claude Code:

```sh
bash ./install.sh --destination "$HOME/.claude/skills"
```

**Windows, PowerShell**, выполнить скачанный код без изменения политики скриптов:

```powershell
& ([scriptblock]::Create((Get-Content -LiteralPath .\install.ps1 -Raw))) -Skill business-lead-research
```

Другой каталог:

```powershell
& ([scriptblock]::Create((Get-Content -LiteralPath .\install.ps1 -Raw))) -Destination (Join-Path $env:USERPROFILE '.claude\skills')
```

Bash-параметр `--skill` можно повторить; PowerShell принимает массив через `-Skill`.
Допустимы только имена двух скиллов этого проекта. Для установки в конкретный проект
укажите его `.agents/skills/` как каталог назначения, вместо пользовательского пути.

## Ручная установка из ZIP

Если не хотите запускать установщик:

1. Скачайте из доверенного Release `business-lead-research.zip` и/или
   `business-website-delivery.zip`, а также соответствующие `.sha256`.
2. Проверьте контрольные суммы из каталога загрузки.
3. Распакуйте каждый архив в новую пустую папку и просмотрите содержимое.
4. Скопируйте полную папку скилла в пользовательский каталог агента из таблицы выше.
   Если там уже есть одноимённая папка, сначала сравните версии и сохраните свои правки.

macOS — проверка первого архива:

```sh
shasum -a 256 -c business-lead-research.zip.sha256
```

Windows — проверка первого архива:

```powershell
& {
  $ErrorActionPreference = 'Stop'
  $archive = 'business-lead-research.zip'
  $expected = ((Get-Content "$archive.sha256" -Raw).Trim() -split '\s+')[0]
  $actual = (Get-FileHash $archive -Algorithm SHA256).Hash
  if ($expected -notmatch '^[0-9a-fA-F]{64}$' -or $actual -ne $expected) { throw 'SHA-256 не совпадает' }
  Write-Output 'SHA-256 совпадает'
}
```

После успешной проверки используйте Finder/Проводник или стандартные `unzip`/
`Expand-Archive`. Переносимая единица — полная папка с `SKILL.md`, `references/`,
`assets/`, `agents/`, лицензией, этой инструкцией и вспомогательными файлами.
Не копируйте один SKILL.md без остальных ресурсов.

Для установки полностью из локальных файлов скачайте выбранный установщик, ZIP
и `.sha256` в одну папку. Укажите её через `--source-dir` в Bash или `-SourceDir`
в PowerShell; сеть тогда не используется.

## Проверка установки и использование

Проверьте наличие `SKILL.md` в каждой установленной папке. В Codex CLI/IDE вызовите
`$business-lead-research` или `$business-website-delivery` в запросе, либо выберите
скилл через `/skills`. В интерфейсе с выбором через `@` используйте его селектор.
Если скиллы не появились, перезапустите агента. Установка не заставляет применять
скилл к каждому запросу.

Node.js 22.18+ нужен только для необязательного TypeScript-экспортёра таблиц внутри
скилла поиска. Это не требование установки или чтения инструкций. Без Node.js агент
может подготовить таблицу доступными ему инструментами или записать CSV самостоятельно.

## Обновление и удаление

Для обновления скачайте новый Release, ознакомьтесь с изменениями и сохраните
локальные правки. Переместите старые папки выбранных скиллов в резервную копию вне
каталогов обнаружения агента, затем установите новые. Не объединяйте старые и новые
references и не рассчитывайте на автоматическую перезапись.

Для удаления удалите только пользовательские папки этих двух скиллов. Проектные
копии и копии в других агентах удаляются отдельно; настройки агента менять не нужно.

Если нет загрузчика Agent Skills, сохраните полную папку в доступной документации
и попросите агента прочесть её SKILL.md. Метаданные `agents/openai.yaml` необязательны
для понимания доменных инструкций; пути и поддержка зависят от среды.
