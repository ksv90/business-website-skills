# Behavioral acceptance cases

| Input or failure | Required behavior |
| --- | --- |
| Listing URL only, no source access | Alternate permitted research or request source details; no invented identity |
| No prices | Omit prices or invite cost enquiry without claiming a free estimate |
| Listing has attractive customer photos | Treat as references until reuse rights are established |
| No verified advantages/reviews | Remove those blocks; use factual service information |
| Phone present, MAX missing | Working phone CTA; no fabricated MAX link |
| Prospect demo with form | Explicit demo state or isolated test endpoint; no real lead submission |
| User requests just a landing page | No unsolicited accounts, commerce or custom backend |
| User requests turnkey booking | Real availability/confirmation contract and staged tests; not a fake calendar |
| 390px viewport with fixed bottom CTA | No overlap with content or form controls |
| Build passes but browser unavailable | Report visual checks not run; do not claim visual acceptance |
| Production launch replaces existing domain | Preserve mail DNS, redirects and rollback; verify authorized switch |
| Public preview contains noindex | Explain noindex does not restrict access; private access if needed |

In a maintenance review, use realistic input material to trace facts into copy and
interactions. Check the resulting artifact, not whether the agent repeated this guide.
