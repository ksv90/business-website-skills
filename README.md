# Business Website Skills

Два переносимых Agent Skills для небольшой веб-студии: от поиска потенциальных
клиентов до готового сайта и передачи владельцу. Начальный продукт — персонализированный
лендинг, который можно показать до покупки. По мере роста те же процессы поддерживают
многостраничные сайты, каталоги, запись, интернет-магазины и заказные приложения.

## Скиллы

| Скилл                                                                  | Вход                                               | Результат                                                                               |
| ---------------------------------------------------------------------- | -------------------------------------------------- | --------------------------------------------------------------------------------------- |
| [business-lead-research](skills/business-lead-research/SKILL.md)       | Город/район, ниша, предложение и лимит поиска      | Проверенный список, CSV/HTML или таблица через доступные инструменты, источники и брифы |
| [business-website-delivery](skills/business-website-delivery/SKILL.md) | Карточка организации, бриф или существующий проект | Код и предпросмотр сайта, проверки, перечень зависимостей запуска и инструкция передачи |

Каждый скилл самостоятельный. Формат: краткий маршрутизатор
`SKILL.md`, подробные `references/`, рабочие `assets/`, метаданные `agents/openai.yaml`,
инструкция установки, лицензия и отдельный Release ZIP. В этом репозитории два скилла,
поэтому архивы названы по скиллам. Версия выпуска общая для совместимости передачи данных.

## Глобальная установка одной командой

Установка использует встроенные средства macOS и Windows. Выполните команду для своей
системы — она скачает установщик из GitHub Release и установит оба скилла для Codex.

**macOS — Терминал:**

```sh
bash -o pipefail -c 'curl -fsSL https://github.com/ksv90/business-website-skills/releases/latest/download/install.sh | bash'
```

**Windows — PowerShell:**

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://github.com/ksv90/business-website-skills/releases/latest/download/install.ps1')))
```

Установщик скачивает ZIP конкретной версии, сверяет SHA-256 и помещает полные папки
скиллов в пользовательский каталог Codex. Node.js, npm, Git и права администратора
для установки не нужны. Существующие скиллы не перезаписываются. Если новые скиллы
не появились в агенте, перезапустите его.

Команды рассчитаны на планируемый публичный адрес `ksv90/business-website-skills`
и начнут работать после публикации первого GitHub Release. Если адрес изменится,
перед публикацией его нужно заменить в командах и установщиках. Подробности, выбор
другого агента, установка отдельных скиллов, обновление и удаление — в [INSTALL.md](INSTALL.md).

## Как использовать

После [установки](INSTALL.md) дайте агенту, например:

> Используй $business-lead-research. Найди 20 автосервисов в Казани для предложения
> готового лендинга. Проверь сайты не только по карточкам. Бюджет платных источников — 0.
> Подготовь таблицу с контактами, источниками, приоритетом и неизвестными данными.
> Никому не звони и не пиши.

> Используй $business-website-delivery. По этой карточке организации подготовь
> персонализированный демолендинг. Не придумывай цены и отзывы. Для российского рынка
> добавь MAX, если найдёшь подтверждённую ссылку. Дай рабочий локальный предпросмотр,
> проверь мобильную версию и перечисли, что понадобится для запуска.

Для большого заказа укажите пользовательские сценарии, интеграции и границы проекта.
Скилл выбирает соответствующий маршрут, а не растягивает лендинг до приложения.

## Что автоматизировано и что зависит от среды

Агент ведёт поиск, сверяет идентичность и сайты, сохраняет доказательства, приоритизирует,
готовит бриф и реализует сайт доступными инструментами. В комплекте есть TypeScript-экспортёр
таблицы с проверкой структуры, безопасным CSV и HTML с поиском. Это не универсальный парсер
карт и не автономная CRM. Браузер, поиск/коннекторы и инструменты разработки предоставляет
среда агента. Платные источники и интеграции требуют соответствующего доступа.

Не обещаем автоматический обход CAPTCHA. Основной путь — подходящий API/экспорт и
несколько источников; при блокировке агент продолжает независимую работу. Ручное прохождение
пользователем остаётся резервом. Отсутствие ссылки в карточке не считается отсутствием сайта.
У API могут быть ограничения на хранение; см. [источники](skills/business-lead-research/references/sources-access.md).

Скиллы не отправляют рекламу и не публикуют официальный сайт без соответствующего поручения.
Они не гарантируют продажи. Демо не содержит выдуманных отзывов, цен, преимуществ или
ложной отправки формы. Это правила качества продукта, а не ограничение на рост студии.

## Проверка и публикация

Требования для сопровождающего: Node.js 22.18+, Bash, zip/unzip, shasum; без npm-зависимостей.

```sh
node scripts/check-skills.ts
node --test tests/*.test.ts
bash scripts/package-skills.sh
bash tests/install.test.sh
```

Архивы, установщики и SHA-256 появляются в `dist/`. CI проверяет материалы, экспортёр
и установщики (Bash и Windows PowerShell);
Release Please готовит версию, затем после одобренного merge выпуска собираются из тега
и прикрепляются к GitHub Release. [Публикация](docs/releasing.md),
[сопровождение](CONTRIBUTING.md), [сценарии проверки](docs/validation.md).

Локальная сборка не означает, что GitHub Release уже опубликован. Автоматизация релизов
не отменяет правила владельца о просмотре изменений, Git-действиях и выпуске версий.
